# Paired Comparisons project documentation

## Navigation

The source code for the repository follows this structure:

```
ROOT /
|--- docs/ : Contains documentation for the repository.
     |--- blog.qmd  : The blog post itself.
|--- src/  : Contains the source code for the repository.
|--- .gitignore  : The files that should not be put in version control.
|--- .pre-commit-config.yaml  : The pre-commit hooks that verify the code before committed.
|--- pyproject.toml  : The Python dependencies required for the project.
|--- README.md  : The entry point to the repository.
```

## More documentation

`dev.md`: Contains instructions on how to set up the environment and for contributing to this repository.
