# Paired Comparison models in `PyMC`, `Turing.jl`, and `STAN`

## Description

This repository contains the source code for a blog post on [blog.damoncroberts.io](https://blog.damoncroberts.io) demonstrating the implementation of a variety of Bayesian paired comparison models in common probabilistic programming languages.
